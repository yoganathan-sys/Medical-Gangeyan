# Sri Siva Medicals - Healthcare & Pharmacy Web Application

A modern, responsive, and user-centric website built for **Sri Siva Medicals (Kangeyan / Gangeyan)**. Designed to provide easy access to essential pharmacy services, prescription enquiries, healthcare guidance, store showcases, and instant WhatsApp communication.

---

## 🌟 Key Features

- **Responsive Modern Design**: Optimized for all devices (smartphones, tablets, laptops, and desktop screens) using clean CSS flexbox and grid layouts.
- **Direct WhatsApp Integration**:
  - One-click prescription upload and enquiry directly via WhatsApp (`+91 9994260284`).
  - Interactive contact form that formats and sends user inquiries directly to WhatsApp.
- **Services Catalog**:
  - Prescription dispensing & medicine support.
  - Over-the-counter (OTC) medicines & wellness products.
  - Surgical supplies, first aid, and diagnostic monitoring devices.
  - Chronic care management, baby care, and personal wellness essentials.
- **Shop Gallery Page (`shop.html`)**:
  - Highlights store infrastructure, well-stocked inventory, hygiene, and trusted customer service.
- **Interactive Location & Map**:
  - Google Maps embed showing the exact store location in Kangeyan with direct navigation links.
- **Interactive UI Elements**:
  - Mobile hamburger navigation with click-outside auto-close.
  - Quick action floating buttons for emergency & enquiry contact.
  - Smooth scroll and polished hover interactions.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/yoganathan-sys/Medical-Gangeyan.git
cd Medical-Gangeyan
```

### 2. Run Locally
Because this is a pure front-end web project with HTML5, CSS3, and JavaScript, no build step or package manager is required:

- **Option A (Direct)**: Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Safari).
- **Option B (VS Code Live Server)**:
  1. Open the project folder in Visual Studio Code.
  2. Install the **Live Server** extension.
  3. Right-click on `index.html` and select **Open with Live Server**.
